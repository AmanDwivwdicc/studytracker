Place your custom alert sounds in this folder:

    sleep_alert.mp3   -> played when the student falls asleep
    phone_alert.mp3   -> played when a mobile phone is detected

Supported formats: .mp3 (needs pygame, included in requirements.txt) and
.wav (played by the Windows fallback backend).

If a file is missing, the dashboard shows a yellow warning that names the
missing file and this folder. You can also select any other file with the
"Browse" buttons and test it with the "Test" buttons.
